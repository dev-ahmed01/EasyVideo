# Integration research – October 2026

This project is intended for Windows, 8 GB RAM, CPU only.

VoiceStudio (https://github.com/debpalash/VoiceStudio): AGPL-3.0 local desktop voice product offering OpenAI-compatible speech POST at localhost port 3900. EasyVideo integrates only the public loopback HTTP API, without vendoring AGPL source. Choose a small CPU-compatible model. Check weights' own terms.

KittenTTS (https://github.com/KittenML/KittenTTS): Apache-2.0, CPU ONNX mini/micro/nano voices (~25–80 MB). Use as a VoiceStudio engine when installed; total memory includes the host and other dependencies.

Piper: the existing standalone offline synthesis option. Separate voice models may have separate commercial requirements.

PySceneDetect (https://github.com/Breakthrough/PySceneDetect): BSD-3-Clause for scene boundaries. EasyVideo currently uses lighter FFmpeg scene scoring and cache, avoiding mandatory OpenCV installation. PySceneDetect remains an optional future evaluation, not shipped in this patch.

MoviePy (https://github.com/Zulko/moviepy): MIT, general compositing, but adds CPU overhead; the existing FFmpeg/Pillow stack is better for a light machine.

Marketing: truthful descriptive title and caption, visible product, real service area only when provided, useful pinned comment, and real enquiry CTA. No hashtags spam, no fabricated pricing, no promises of reach.

Never clone a voice without consent or use unlicensed music in ads. Review each Reel's visual cuts, title placement and audio on a phone before publishing.
